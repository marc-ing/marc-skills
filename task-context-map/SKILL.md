# 任务上下文地图

只进行只读分析并输出地图。除非用户明确要求，不实施任务中的代码改动。

## 工作流程

1. 将用户目标拆成可搜索的功能名、符号名、路径、配置项和错误信息。
2. 使用文件搜索和文本搜索定位入口，再沿导入、调用、类型和配置关系向外扩展。
3. 查找直接测试、集成测试、测试夹具和相似实现。
4. 区分必须修改、可能受影响、仅供参考的文件。
5. 对每个结论给出文件路径和简短依据，不凭目录名猜测用途。

## 测试与参考实现

列出相关测试、夹具和可复用模式。

## 风险与未知项

记录公共接口、数据迁移、配置变更、兼容性和仍需确认的信息。

## 边界

- 优先小范围、可验证的关系，不追求列出整个仓库。
- 文件与任务关系不明确时说明置信度。
- 不把生成文件、依赖缓存和无关构建产物列入地图。
- 不声称已完整覆盖动态调用或运行时配置，除非有证据。
