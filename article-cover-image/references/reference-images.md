# 参考图片处理

## 识别输入

参考图可能来自：

- 用户通过 `--ref` 提供的路径。
- 当前消息上传或粘贴的图片。
- 用户明确指出的当前工作区图片。

不要把文章正文中的普通插图自动当作封面参考图，除非用户明确要求。

## 保存

把参考图复制到输出目录：

```text
references/ref-01-{slug}.{ext}
references/ref-02-{slug}.{ext}
```

保留原文件和原格式。目标文件已存在时追加时间戳，不覆盖用户文件。

## 用途

| 值 | 含义 |
|---|---|
| `direct` | 后端直接读取图片；主体、人物或构图必须被参考时使用 |
| `style` | 只提取线条、材质、光影、构图和细节密度 |
| `palette` | 只提取背景、主色、强调色和色彩比例 |

`direct` 图片写入提示词 YAML 的 `references`，并传给支持参考图的后端。`style` 和 `palette` 只把分析结果写进提示词正文。

## 深度分析

逐张记录：

1. 主体：画面中最重要的人物、物体或符号。
2. 构图：视角、焦点位置、留白、层次和阅读方向。
3. 风格：线条粗细、边缘软硬、纹理、颗粒、阴影和精细度。
4. 配色：背景、主色、强调色及大致占比。
5. 文字：位置、层级和气质；不得复制原文无关文字。
6. 可保留与可调整项：明确边界，不写模糊的“参考整体感觉”。

## 人物参考

参考图中的人物需要出现在封面时：

- 必须让用户明确该人物应被保留。
- 使用支持参考图的后端，并把图片标为 `direct`。
- 描述发型、眼镜、服装、姿态等必要特征，但不推断敏感属性。
- 用户未明确要求时，不识别人物身份，不把真人转换成其他敏感或误导性场景。
- 后端不支持参考图时，说明无法可靠保持人物一致性，让用户选择更换后端或使用不可识别的原创人物。

## 优先级

1. 用户当前明确要求。
2. 用户提供的直接参考图。
3. 用户指定的风格或配色。
4. `EXTEND.md` 默认值。
5. 自动选择规则。

参考图与文章主题冲突时，指出冲突并提出调整方案，不擅自忽略参考图。

## 生成前验证

- 所有参考图路径存在且可读取。
- `direct` 图片数量不超过后端限制。
- 提示词明确哪些特征必须保留、哪些可以调整。
- 没有要求复制参考图中的水印、签名、品牌或无关文字。
- 用户没有误以为仅靠文字描述就能保持特定人物身份。
