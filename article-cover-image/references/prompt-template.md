# 封面提示词模板

生成前把完整最终提示词保存为 `prompts/01-cover-{slug}.md`。文件内容必须可以直接交给图片生成后端，不能留下待补占位符。

## 文件格式

```yaml
---
type: conceptual
palette: cool
rendering: digital
text: title-only
mood: balanced
font: clean
aspect: "16:9"
language: zh
output: ../cover.png
references:
  - filename: ../references/ref-01-example.png
    usage: direct
---

# 任务

生成一张文章封面位图，不是正文信息图。

# 内容语境

- 文章主题：……
- 核心观点：……
- 目标读者：……
- 使用场景：……

# 视觉设计

- 构图类型：conceptual
- 配色：cool
- 绘制方式：digital
- 核心视觉隐喻：……
- 主体：……
- 辅助元素：……

# 文字

- 文字密度：title-only
- 标题原文：“……”
- 语言：简体中文
- 不添加副标题、署名、日期、标签或其他文字

# 情绪与字体

- 情绪：balanced，中等对比和饱和度
- 字体气质：clean，清晰现代的无衬线气质

# 构图

- 比例：16:9
- 主视觉位置：……
- 标题安全区：……
- 保留约 45% 呼吸空间
- 缩略图尺寸下主体和标题仍然清楚

# 参考图

- 必须保留：……
- 可以调整：……
- 禁止复制：无关文字、标志、水印和签名

# 禁止项

- 不添加提示词未列出的文字、数字、品牌、网址、二维码、水印或签名。
- 不生成照片素材拼贴感、模板化商务握手、无关灯泡或火箭。
- 不复刻受保护角色或可识别的真实人物。
- 不让文字贴边、遮挡主体或出现伪文字。
```

没有直接参考图时省略 `references`。只借鉴风格或配色时，把分析结果写入正文，不传原图。

## 内容驱动设计

从文章中提取一个核心视觉命题，并将其转成画面关系：

- “复杂系统如何协作”可转为模块、连接和流动方向。
- “旧方法向新方法转变”可转为两种空间、路径或材质的变化。
- “个人成长”可转为尺度、路径、光线或环境变化，但避免陈旧的登山剪影。
- “风险与机会并存”可转为平衡、分岔或张力，不自动使用红绿对半。

视觉隐喻必须能由文章内容解释。若只能得到通用素材图，应改用更直接的 `conceptual` 或 `typography` 构图。

## 类型构图

### `hero`

- 主视觉占约 60%–70%。
- 标题与主体形成一个整体，避免把文字单独塞进空角落。
- 使用明显的尺度、光线或对比建立冲击力。

### `conceptual`

- 用 2–4 个抽象元素表达核心关系。
- 信息结构清晰，但不要画成正文流程图。
- 保留一个明显焦点和足够留白。

### `typography`

- 标题占画面约 40% 或更多，成为主要视觉。
- 辅助图形数量受控，只负责增强主题。
- 标题较长时使用两到三行稳定排版，不擅自删字。

### `metaphor`

- 选择一个具体、可解释的视觉隐喻。
- 隐喻与文章观点之间要有明确对应关系。
- 避免灯泡、拼图、握手、靶心和火箭等默认素材。

### `scene`

- 明确时间、地点、主体动作、光线和情绪。
- 场景需要体现文章中的关键经验，不只是漂亮背景。
- 人物面部不必写实，优先原创、简化形象。

### `minimal`

- 只保留一个主元素和极少辅助形状。
- 至少约 60% 留白。
- 使用位置、比例和色彩关系表达主题，避免细节堆叠。

## 标题规则

- 标题逐字使用用户或原文提供的版本。
- 禁止自行生成副标题、栏目名、日期和作者信息。
- `none` 时明确写“画面中不得出现任何可见文字”。
- `title-subtitle` 只有在原文明确存在副标题时使用。
- `text-rich` 中的关键词必须由用户提供或能在原文逐字找到。
- 中文标题指定“简体中文，字形清楚”；英文标题指定准确大小写。

## 参考图写法

直接参考图：

```text
REFERENCE — MUST USE:
- 主体：保留人物或物体的必要识别特征
- 构图：保留主次关系和视角
- 调整：背景与配色可以适配当前文章
- 排除：不复制原图文字、标志、水印和签名
```

风格参考图：

```text
REFERENCE STYLE — INCORPORATE:
- 线条：粗细不均的墨线
- 材质：米白纸张和轻微颗粒
- 色彩：低饱和暖色，强调色占比很小
- 构图：单一焦点，四周留白
```

不要只写“模仿参考图”或“和某位艺术家一样”。

## 生成前检查

- 文件已保存，所有占位符已替换。
- 六个维度、比例和语言完整。
- 标题与原文逐字一致。
- 输出路径和参考图路径真实有效。
- 参考图用途明确，后端支持 `direct` 输入。
- 禁止额外文字、署名、品牌、水印和签名。
- 构图适合目标平台和缩略图尺寸。
