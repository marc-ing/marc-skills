# 命令速查页

围绕一个命令提供最常用、可复制的示例，不写成完整手册。

## 所需输入

- 命令名称。
- 官方文档、man page 或该命令的帮助输出。

缺少命令名称时询问用户。缺少资料且允许联网时查找官方文档；否则请用户提供帮助输出。

## 工作流程

1. 确认命令版本、操作系统和子命令差异。
2. 从权威资料中筛选 5–8 个最常见的任务。
3. 每个任务写一句说明和一条可复制命令。
4. 用清晰的示例值替换复杂参数，但避免难以辨认的占位符。
5. 对照资料检查选项名称、参数顺序和互斥关系。

## 输出格式

# command

> 一句话说明用途。
> 必要时补充平台或版本限制。

- 完成某项常见任务：

    command example

- 完成另一项常见任务：

    command example

更多信息：官方文档链接。

## 边界

- 不包含未经验证的选项。
- 不加入危险命令，除非用户明确需要，并清楚说明影响范围。
- 不堆叠罕见参数或重复示例。
- 不把外部博客当作唯一依据；优先官方文档和命令自带帮助。
